# Kitty Goldfinger (KGF) Handicapper

A Streamlit web app built to honor my mom's handicapping techniques and wisdom.

### Features
- Smart KGF Scoring System (Speed + Stamina + Board Hit Rate + Pedigree)
- High Odds Board Hitter Detection (🔥)
- Triple Crown / Secretariat Pedigree Bonus (👑)
- Race Card Predictions with manual entry
- Pick 5 Builder
- Multi-track support (Laurel Park, Santa Anita, Preakness, etc.)

### How to Use
1. Go to the **Race Card Predictions** tab
2. Select a race and click **"Load Race Field"**
3. Edit the horses if needed
4. Click **"🚀 Run KGF Predictions on Full Field"**
5. Use the scores and highlights to build your boxes and Pick 5s

### Built With
- Streamlit
- Mom's proven handicapping logic
- Grok AI assistance
